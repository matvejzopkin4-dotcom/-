# P2P: С НУЛЯ

Лёгкая браузерная игра по мотивам дизайн-документа «P2P: С нуля». Тебе 20 лет, ты живёшь в Новозаровске и у тебя 3 700 ₽ на карте. Нужно стать P2P-мерчантом, научиться отличать оборот от прибыли, не попасться мошенникам и банку, собрать команду и дойти до одного из четырёх финалов.

## Как запустить

Без сборки, сервера и зависимостей: откройте `game/index.html` в браузере. Прогресс сохраняется в браузере автоматически.

Можно и через локальный сервер: `python3 -m http.server` в корне репозитория, затем http://localhost:8000/.

Для публикации включите GitHub Pages (Settings → Pages → ветка `main`, папка `/ (root)`): корневой `index.html` перенаправляет на игру.

## Структура

```
game/
  index.html   разметка
  style.css    оформление (тёмный терминал, мобильная версия)
  data.js      контент: персонажи, главы, события, апгрейды, финалы
  engine.js    игровая логика без DOM, детерминированный RNG
  ui.js        рендер, анимации, звук (WebAudio), сохранения
  tests/       тесты движка и бот для проверки баланса
111/           первый прототип (Python-сервер + терминал из 12 вкладок)
```

## Тесты и баланс

```
node --test game/tests/*.test.js   # тесты движка
node game/tests/sim.js 30          # бот проходит игру 30 раз и печатает статистику
```

Полное прохождение у бота занимает около 45–75 игровых дней.

Все персонажи вымышлены. Переводы через чужие счета и обход банковского контроля в игре приводят к блокировкам и краху.
